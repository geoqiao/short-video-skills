# 平台规则

核对于 2026-10。平台会改，发布前以投稿页为准。

| 事项 | 做法 | 依据 |
| --- | --- | --- |
| 画面、口播、字幕、文案里的网址 | 不出现。来源写名称（"作者博客实测""某某官方文档"），不写域名 | B 站[《关于违规推广行为的治理公告（二）》](https://www.bilibili.com/opus/942458606667694096)（2024-06-13）把"网址链接"列入站外导流，可限制传播；[《抖音社区自律公约》](https://www.douyin.com/rule/policy)第 34 条禁止"第三方平台账号"一类导流信息 |
| 落款 | 只写站内账号名，不写其他平台的账号 | 同上 |
| 引导语 | 不说"去某网站看""搜索某某"。可以引导评论、关注、看合集 | 巨量星图[《内容营销规范升级公告》](https://www.xingtu.cn/help-center/author/144150)对"引导话术"的定义 |
| AI 声明 | AI 配音或 AI 画面都要声明。B 站：创作声明 → 含AI生成内容。抖音：自主声明 → 内容由AI生成。视频号：视频标注 → Contains AI-generated content（发表页显示为英文）。小红书：内容类型声明 → 笔记含AI合成内容 | B 站[《关于AI生成内容有序标识的公告》](https://www.bilibili.com/opus/1106496554576904197)（2025-08-29）和[专项公告](https://www.bilibili.com/opus/1202507670848798745)（2026-05-15，漏标可打回或下架）；抖音[治理 AI 技术滥用公告](https://trust.douyin.com/article/15868)（2025-06-13） |
| 抖音话题数 | 网页端一条最多 5 个，第 6 个不生效还会打乱光标 | 2026-10-12 在发布页实测 |
| 抖音标题 | 上限 30 字 | 发布页计数 |
| 视频号话题 | 写在描述里，`#词` 自动变成话题，不显示浏览量；6–7 个都生效 | 2026-10 在发表页实测 |
| 小红书标题 | 上限 20，英文和数字按半个字计 | 发布页计数 |
| 小红书正文 | 上限 1000 字，会被站内搜索 | 发布页计数 |
| B 站话题 | 一条稿件只挂一个 | 2026-10-11 投稿页 |
