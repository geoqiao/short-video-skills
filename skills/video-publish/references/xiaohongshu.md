# 小红书创作服务平台

发布页：`https://creator.xiaohongshu.com/publish/publish?source=official`。核对于 2026-10-12。

| 环节 | 现象 | 做法 |
| --- | --- | --- |
| 上传 | 拖放不触发上传 | `sh scripts/xhs-inject-video.sh <mp4> <文件名> <out.js>` 再 `run-code`，注入 `accept` 含 mp4 的 file input |
| 标题 | 上限 20，英文和数字按半个字计 | 写"问题 + 一个结论" |
| 正文 | tiptap 编辑器，上限 1000 字 | 用 DOM 把光标放到编辑器末尾再 `keyboard.insertText`，逐行按 Enter |
| 话题 | 输入 `#词` 约 2.5 秒后出下拉，带浏览量；按 Enter 选第一项 | 核对 `a.tiptap-topic` 的个数。注意同名词混进别的领域（`#token` 混有加密货币内容） |
| 封面 | 默认截首帧并裁成 4:3，会切掉标题 | 鼠标移到封面缩略图上点"编辑封面" → 用 `scripts/xhs-inject-image.sh` 的脚本传 3:4 图 → 左侧"裁剪"选 3:4 → "完成"。页面出现"封面效果评估通过" |
| 合集 | 要先在网页上建好 | 点"选择合集"选它 |
| 内容类型声明 | 选项：虚构演绎 / 笔记含AI合成内容 / 内容包含营销广告 / 内容来源声明 | 选"笔记含AI合成内容" |
| 原创声明 | 开关，默认关 | 不代开，由作者决定 |
| 地点 | "添加地点"是输入框 | 逐字输入，选对的那一项 |
| 关联活动 | 页面只露两张卡，"更多"里有很多官方活动，不能搜索 | 在"更多活动"抽屉里按名字找对口的，点卡片上的"关联活动"；平台会自动往正文加活动话题 |
| 换视频 | 上传后页面仍留着 mp4 的 file input | 再跑一次注入脚本；标题、正文、话题、封面、合集、声明、地点、活动都会保留 |
| 两条一起填 | 每个标签页一张表单 | 第二条用 `tab-new` 再开一个发布页 |
